# TaskPilot AI v0.1.0

TaskPilot AI v0.1.0 is the first portfolio release of a human-governed, graph-based software
delivery orchestrator. It demonstrates deterministic workflow control around probabilistic model
calls without presenting the system as a hostile-code sandbox or multi-tenant platform.

## Highlights

- **Real LangGraph orchestration:** typed partial state, parallel architecture/repository analysis,
  a persisted human interrupt, deterministic conditional routes, and bounded validation/repair.
- **Provider-neutral LangChain integration:** structured Pydantic output and explicit routing across
  OpenAI, Anthropic, OpenAI-compatible, and local OpenAI-compatible configurations.
- **Durable and observable execution:** SQLite/PostgreSQL checkpoints, restart-safe approval resume,
  replayable SSE, structured logs, and optional LangSmith tracing.
- **Constrained repository effects:** canonical path enforcement, application-owned stale-write
  guards, atomic writes, fixed Git inspection, and shell-free command allowlists.
- **Complete reviewer experience:** FastAPI API, CLI, graph-first React UI, Docker Compose demo,
  sample repository, screenshots, ADRs, architecture guide, and deterministic evaluations.

## Validation evidence

- Backend formatting, linting, strict mypy, package build, pre-commit, and 65 passing tests at
  85.35% coverage.
- Frontend formatting, linting, 4 passing Vitest tests, and production build.
- Python and production JavaScript dependency audits plus GitHub CodeQL configuration.
- Docker Compose build/startup/health and a completed PostgreSQL-backed sample workflow.
- Opt-in live-provider harness with two documented scenarios and a machine-readable execution trace.

Release-gated live-provider Scenario A completed successfully through approval, implementation,
real validation, one bounded repair, review, and final reporting. Its sanitized trace is committed
as release evidence; Scenario B remains recommended but was not a release gate. See the
[release-readiness evidence](../release-readiness.md) for exact gate results and Docker run details.

## Published artifacts

The Python package is available from [PyPI](https://pypi.org/project/taskpilot-ai/0.1.0/), and the
API and web images are public on GHCR with `0.1.0`, `0.1`, and `latest` tags:

```bash
python -m pip install "taskpilot-ai==0.1.0"
docker pull ghcr.io/chasesaurabh/taskpilot-ai:0.1.0
docker pull ghcr.io/chasesaurabh/taskpilot-ai-web:0.1.0
```

The container images include GitHub build-provenance attestations. The successful
[publishing workflow](https://github.com/chasesaurabh/taskpilot-ai/actions/runs/33351719786)
built all artifacts from the immutable `v0.1.0` tag.

## Try the demo

```bash
docker compose up --build
```

Open `http://localhost:5173`, start the prefilled pagination task, inspect the approval evidence,
approve it, and watch validation complete. The deterministic path requires no model API key.

## Known limitations

- Designed for one trusted developer; no authentication or tenant isolation is included.
- Repository commands execute on the host/container and can run repository code. Use disposable
  isolated workers for untrusted inputs.
- There is one approval boundary before writes and commands.
- Crash-safe resume is proven at approval, not as a general exactly-once guarantee for side effects.
- Model behavior depends on provider structured-output support and quality.
